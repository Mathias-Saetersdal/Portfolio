Accessibility

This site aims for WCAG 2.2 at level AA. This page says how it was tested, what still does not work, and how to tell me if something stops you.

How the site was tested

The last test was on 21 October 2026. Every page in Norwegian and English was run through axe-core. I went through each page with the keyboard and viewed each one at 320 pixels wide.

The test found three problems. Text on the project cards lost contrast when the pointer was over the card. An English title was not marked as English. The 404 page had no main region. All three were fixed the same day.

What does not work yet

  • The master's thesis PDF is not tagged. A screen reader reads it as one long text, with no headings or lists. It will be exported again with tags.

  • In the Diskette app at diskette.saetersdal.no, Enter and Space do not open a case. Only a mouse click does (WCAG 2.1.1).

  • In the same app, the button does not say whether a row is open or closed. A screen reader user is not told that anything happened (WCAG 4.1.2).

The time limit in the colour test

The colour test on the colour and memory page has fixed times: 15 seconds to look at the image, 10 to count and 90 to write. The test repeats a study that used the same times, so the timing is part of the task. WCAG 2.2.1 allows fixed times in that case. You can stop the test at any point, and a separate button reads out how much time is left.

What has not been tested

  • The site has not been read with a screen reader such as NVDA or VoiceOver. Names and roles were checked in the code and by axe-core.

  • The colour test has not been run all the way through with a keyboard. It starts from the keyboard, and its fields have names.

Report a problem

If something on the site stops you, email mathias@saetersdal.no. Say which page it was and what happened.
